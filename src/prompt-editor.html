定制表达教练

底层词库和基础反馈规则始终生效。这里用于叠加你的训练目标、触发规则和表达风格。

底层系统规则 锁定
14 条实时反馈规则、词库高亮、完整报告模板保持启用。它们覆盖重复、结论缺失、听众视角、主题漂移、立场模糊、填充词、犹豫词和笼统词等基础训练场景。
训练模式 可编辑

不同训练模式会调整实时反馈和最终报告的关注重点。

我的训练目标 可编辑

你现阶段最想改善的表达问题。AI 会据此调整反馈优先级。

我现在最大的问题是：说话太散，经常跑题；口癖「然后」「就是」太多；描述事情总用「很好」「挺不错的」，缺少具体画面。
自定义触发规则 可编辑

格式：触发条件 -> 输出什么提示。它会和底层规则一起生效。

连续两个「非常」 -> 「换个程度词」；出现「怎么说呢」 -> 「别绕，直说」；讲了观点但没给原因 -> 「为什么？」
我想要的表达风格 可编辑

描述你理想中的说话方式，AI 会在反馈时以此为标准。

我的口癖补充 可编辑

你自己特有的口癖或高频词，底层词库没覆盖到的内容。

自定义词库 可编辑

补充底层词库没有覆盖的填充词、犹豫词和精准替换候选。每行一个词；替换词使用「原词=替换1,替换2」格式。
